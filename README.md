![Status](https://img.shields.io/badge/Status-Deployed-brightgreen?style=flat-square)

A full-stack event ticket booking platform designed to handle real-time seat availability, concurrent bookings, secure authentication and transactional workflows.

**Core Engineering:**

- Venue, section, seat and event management.
- Transactional multi-seat booking workflows.
- Prevention of concurrent double-booking using PostgreSQL transactions and pessimistic row-level locking.

- Automated booking expiration and transactional seat recovery.

- Redis-based caching.
- JWT authentication, Google OAuth 2.0 and refresh token rotation.

- QR-based PDF ticket generation.
- Structured logging, correlation IDs and application health checks.
- Docker-based cloud deployment.
